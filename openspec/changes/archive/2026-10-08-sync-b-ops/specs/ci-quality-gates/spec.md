## ADDED Requirements

### Requirement: verify-parte has a fourth part for fences and the shell kit
The `verify-parte` matrix SHALL have parts 1 to 4, run `pnpm test:unit --project produto --shard=<parte>/3` only on parts 1–3, and run `pnpm cercas` and `pnpm test:shell` only on part 4, with the time-budget message naming `<parte>/<job-total>`.

#### Scenario: Shell kit grows
- **WHEN** a pull request adds shell test cases to `test:shell`
- **THEN** they run in part 4 and do not lengthen the unit-test parts

### Requirement: A major release is cut only on explicit request
`calcularBump` SHALL return `major` only when called with `pedidoMajor = true` (flag `--major` of `scripts/cortar-release.ts`, boolean input `major` of the `release.yml` dispatch), and a fragment with `impacto: exige_acao` SHALL produce at most `minor`.

#### Scenario: Fragment that requires action
- **WHEN** the release is cut from fragments including one with `impacto: exige_acao` and no `--major`
- **THEN** the computed bump is `minor`

### Requirement: e2e keeps the visual evidence generated by a passing run
On success each e2e part SHALL copy the untracked or modified files under `evidence/` into an artifact `evidencia-parte-<parte>` retained for 7 days, warning when there is none.

#### Scenario: Passing part with new screenshots
- **WHEN** an e2e part passes and its specs wrote new captures under `evidence/`
- **THEN** the run has an artifact `evidencia-parte-<parte>` containing only those captures
